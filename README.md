# Homebrew tap of Cicord

```sh
brew install cicord/tap/cicord
```

`Casks/cicord.rb` is written by the release workflow of [cicord/cicord](https://github.com/cicord/cicord) at each release, from the release archives and their checksums. Do not edit it by hand.

Documentation: https://cicord.dev/docs/getting-started/installation/
